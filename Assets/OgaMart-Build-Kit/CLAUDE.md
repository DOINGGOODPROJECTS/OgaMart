# OgaMart – project rules for Claude Code

Read `CLAUDE_CODE_PROMPT.md` first. It is the full brief. This is the short version that applies to every session.

- **The goal:** a GDevelop 5 project in `game/` (Android, 1170×2532 portrait) generated by `tools/build-project.mjs`. Never hand-edit `game/game.json`: change the generator and rerun `node tools/build-project.mjs`.
- **Sources of truth:**
  - rules: `docs/OgaMart-Design-Document.txt`
  - looks: `screens/*.png` and `ui-kit/layout/*.json`
  - numbers: `scripts/game/ogamart_data.js`
- **Logic** lives in `scripts/game/ogamart_game.js` and has no GDevelop calls. Wiring lives in `scripts/game/ogamart_bridge.js`. UI motion lives in `scripts/ui/ogamart_ui.js`. All four script files are pasted into the `Boot` external events by the generator.
- **Art:** only the provided art in `assets/` and `ui-kit/assets/`. Object names follow the asset names and `ui-kit/GDEVELOP_SETUP.md`.
- **After any logic or balance change:** run `node tests/simulate.js 6`. Level 4 should come within 5 minutes and level 10 within 1–3 hours.
- **Milestones:** M0 setup, M1 prototype, M2 all screens, M3 full content, M4 polish and Android. Stop after each milestone, update `PROGRESS.md`, commit, and wait for approval.
- **Ask before:** deleting files, changing a rule from the design document, or when a screen and the document disagree.
- **Comments:** short and plain.
