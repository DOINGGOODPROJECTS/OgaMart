# Screen by screen: which kit parts each screen uses

Every screen of the UI/UX (the 42 PNGs) was measured element by element. For each screen you get:

- `layout/<screen>.json`: every box, text, icon and character with its position and size in pixels (1170x2532 screen), colours, font, size and the matching kit asset (`kit_asset`).
- `layout/annotated/<screen>-annotated.png`: the screen with a coloured frame and label on every kit part. Pink frames are characters (use the character PNGs from the asset pack).
